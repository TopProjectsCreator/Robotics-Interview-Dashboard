---
name: Shared Parts supplier catalog
description: The supplier product catalog is common across teams while each team's inventory details stay private.
---

Supplier product rows should be shared across teams because teams buy from the same vendors and duplicating catalog records wastes space. Team-owned stock quantities, saved costs, storage locations, notes, quote snapshots, and manual catalog entries remain team-specific.

**Why:** The project owner explicitly said the same suppliers should have one shared catalog rather than separate copies for each team.

**How to apply:** When changing Parts catalog storage or visibility, treat synced supplier products as shared records and apply the active team's scope to inventory and manual data.
