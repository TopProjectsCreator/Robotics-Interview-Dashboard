# Robotics Chat Tutorial — 60-second film script

## Production brief

- **Format and runtime:** 16:9, exactly 60 seconds, 12 connected shots; captions remain inside the central safe area.
- **Audience and promise:** Robotics-team members learn how to use one shared dashboard for chat, decisions, files, voice input, and team workspaces.
- **Privacy:** Use only fictional people, messages, files, and project content. Keep the personal password masked. The explicitly requested team access code `hi` is the only visible credential.
- **Product integrity:** Show the production dashboard URL exactly. Reconstruct interface elements as original animation; do not use screenshot pixels, copy screenshot names or conversation text, alter accounts, or imply Microsoft compatibility.
- **Identity:** Deep robotics navy, teal interaction color, warm yellow focus accent, and Space Grotesk / DM Sans / JetBrains Mono. The simple `R` monogram is a tutorial lockup, not a claimed official logo.
- **Audio:** One continuous, original locally synthesized instrumental bed at 100 BPM, rendered from an exact 60-second source. No narration, speech, recorded voice, SFX, or other audio layer. Its gentle lift aligns with the shared-tool sequence; the final second fades out.

## Director's treatment

- **Promise:** Team chat can coordinate a complete robotics workflow without separating its conversations, files, and shared work.
- **Identity:** Navy, teal, and warm yellow; Space Grotesk display type paired with DM Sans and JetBrains Mono.
- **Hero:** The dashboard's interface, treated as a set of crafted paper, glass, and grid surfaces rather than a static screen recording.
- **Motion:** A persistent yellow/teal focus ring, compound mask-and-scale handoffs, and close UI choreography that reveals each action.
- **Arc:** Start with the production URL and access code, move from personal setup into increasingly collaborative tools, then resolve to a centered invitation to return to the dashboard.
- **Payoff:** The final URL and `hi` badge hold clearly for more than two seconds; the closing ring returns to the opening access-code position for a clean loop.
